## 什么是网站？


过去几年，我一直在教授交互设计与互联网相关的课程。


我是在大学的艺术相关院系里教课，所以我们会讨论互联网如何影响艺术，也会反过来看艺术如何影响互联网，以及科技进步为什么经常与艺术发展同步发生。


课堂上，我们会制作网站。为了做到这件事，我们会学习构成网页最基本的标记与编程语言——HTML、CSS，以及一些 JavaScript。


然而，有时一个学期结束后，我还是会收到学生困惑的 Email，问我：


“所以，我到底要怎么**真正做出一个网站**？”


这也让我开始问自己：


“话说回来，网站到底是什么？”


我们很容易忘记这件事。今天，制作网站的方法多到数不清，选择多得令人无所适从。但从最根本来看，网站其实一直都没有改变：


网站，就是放在某处服务器上的一个文件，或一组文件。


服务器是一台持续连接互联网的电脑。当有人输入你的网址时，服务器就会把你的网站发送出去。通常你需要付费使用服务器，也需要付费购买域名。


域名是一串人比较容易理解的文字，用来指向一个 IP 地址；而 IP 则是一串数字，代表你的服务器位于哪里。


链接——默认通常显示为蓝色并带有下划线——是网络的氧气。它们就是 HTML 里的“HT”，也就是 hypertext（超文本）的核心。


不是每一个网站都有链接，但所有链接都会把你带往其他网页：可能仍在同一个网站里，也可能前往别的地方。


可是，这些我的学生早就知道了！


所以，当他们问我到底要怎么**真正做一个网站**时，他们其实是在问：


要怎么做一个存在于**今天这个世界里**的网站？


我们应该承认，今天的网络，已经和许多人从小熟悉的那个网络很不一样。


因此，学生明明已经“学会”了做网站，却还是会问该怎么做，真正困住他们的，其实是 2018 年制作与维护网站时伴随而来的技术阻力，以及社会压力。


那些人人都在使用的社交网站——Facebook、Instagram、Snapchat、Pinterest 等——乍看之下可能很友善、很方便，但它们终究是私人企业，而且广告利益的优先级高于用户的需求。


用户快不快乐，并不是它们最主要的考量。


所以，当你使用社交媒体，甚至只是想到社交媒体时感到焦虑，其实再正常不过。


在这个由大型平台主导、充斥数字噪音的年代，没有人会替你照看你自己——除了你自己。


因此，当有人告诉我，他希望自己的网站能够“把事情说清楚”，清楚表明自己是谁、在做什么，我完全可以理解。


然而，“清楚”只是网站众多可能目的中的一种。


人还有很多不同的心理状态，都可以通过网站传达。


一个令人惊喜的网站、一个让人难忘的网站、一个宏大的网站、一个令人平静的网站、一个震撼的网站、一个难以预测的网站、一个无聊到极致的网站、一个古怪的网站、一个让人大开眼界的网站、一个非常安静细腻的网站，或者单纯一个很棒的网站——都可以成立。


你甚至不需要只做一个网站。


说不定，你就是想用好几个网站让人困惑，或给人惊喜。


我最喜欢网站的一点，是它同时具有两种身份：它既是主体，也是客体。


换句话说，网站的创作者同时是作者，也是建筑师。


网站可以成为什么，几乎没有尽头。


网站是一个什么样的房间？


或者，网站其实更像一栋房子？


一艘船？


一朵云？


一座花园？


一滩水洼？


无论它是什么，都可能形成一种自我反馈的循环：


当你把心力投入网站，网站也会反过来塑造你的身份。


## 为什么要有自己的网站？


我们比任何时候都更需要由一个个人，而不是由企业，来引导网络的未来。


Web 之所以叫作“网”，正是因为它的生命力依赖这样的结构——一个个彼此连接的独立节点，共同为庞大的网络注入生命。


这张网真正应该服务的是人，而不是由少数几家大型企业——例如 Facebook／Instagram、Twitter 和 Google——提供动力并掌控方向。


只要拥有自己的网站，每一个人其实都可以把 Web 拉回它最初的架构。


我尤其认为，艺术家可以在这件事上扮演关键角色——让世界看见，Web 还能走向哪些地方。


艺术家很擅长创造世界。


他们先替自己创造一个世界，然后在分享作品时，也替其他人打开那个世界。


而所谓“建构世界”，当然意味着你得创造一切。


你不只是制作这个世界里面的东西，也要创造包围它们的整个世界——它的语言、风格、规则与建筑。


这正是网站如此重要的原因。


网站让作者不只可以创造作品，也就是那些“物件”，还能创造承载作品的世界——房间、房间的排列方式，以及整体的建筑。


理想状态下，这两者会彼此影响，形成一个良性、不断自我完善的循环。


对艺术家的创作实践而言，这可能是一件非常滋养人的事。


每当有创作者说：


“我不需要网站。”


我会反问：


为什么不做一个能在策略上与其他活动并行的个人网站？


网站怎样才能补足你原本就在做的事，而不是和它竞争，或只是把同样的东西再做一次？


你怎么让制作网站这件事，对自己而言变得有趣、引人思考，或者带来任何你想要的感受？


制作与培育一个网站的过程，又能怎样反过来影响你的创作方式？


网站可以是任何东西。


它不必——而且很可能也不应该——成为你所有作品的完整档案库。


因为那样的东西，在你发布的那一刻就已经死了。


网站，以及任何互动性的事物，本质上都处于未完成状态。


它不完美。有时甚至还会有几个 bug。


但这正是它美丽的地方。


网站是活着的，也是具有时间性的空间。


话说回来，网站死去之后，究竟会发生什么事？


## 网站可以是什么？


### 网站是一间房间


在信息过载的时代，房间令人安心，因为它有边界，而且通常有某个特定用途。


_Louis Rosetto_


同时，房间也可以非常有弹性。


你可以根据不同场合重新排列里面的东西，甚至暂时加上一面隔断。


你也可以把不同元素放在空间里彼此并置，或者利用链接打开通往隔壁房间的入口。


在 The Creative Independent（TCI）成立初期，我们有时会把 TCI 的网站想象成一栋建在河边的房子。


我们把那些访谈想成不断流动的河水，因为它们是这栋房子的养分，也是生命来源。


每天，我们都从河里取水、喝水。


但有时，根据水里养分组成的不同，河水也会改变我们的房子。


我们可能一觉醒来，发现原本挂着画框的地方，突然多出了一扇门。


**知识成了建筑师。**


当然，任何隐喻都不可能完美。


不论是好是坏，要拆掉一栋建筑，远比删除一个网站困难多了。


_Orit Gat_


### 网站是一个架子


如果把视线拉近，看看这栋房子里的这个房间，我们会看到一个架子。


或许，比起思考一整个房间，先想象一个架子要容易一些。


架子上要放什么？


书？


生活中收集来的物件？


当然，都可以。


幸好架子上没有什么太重的东西，不然架子可能会垮掉。


放几样小东西就够了——它们可以承载知识，也可以完全不承载什么。


而且，东西越轻，就越容易更换。


有一本书或一件小饰物已经“太去年”了吗？


那就把它拿下架吧。


想一想，你可以在这个小小的架子上，创造出哪些出人意料的并置。


### 网站是一株植物


植物是催不得的。


它们会按照自己的方式生长。


你的网站也可以如此——只要选对土壤，替它浇水，但不要浇太多，再给它足够的阳光。


某一天，种下一颗想法的种子，然后让它慢慢长大。


也许过了几年，它才会开花。


运气好的话，再过一年，它可能结出果实。


果实可以是朋友，可以是欣赏，也可以是金钱——成功有很多种形式。


但别太兴奋，也别急着替自己设定目标。


这里谈的不是那回事。


我说过了：


**植物是催不得的。**


_Paul Ford_


### 网站是一座花园


Fred Rogers 曾说，你可以在自己的心灵花园里培育想法。


有时，等这些想法长成小小的幼苗，已经可以自己站稳之后，把它们移到外面的花园，种在其他幼苗旁边，也会很有帮助。


花园每个季节都有自己的节奏。


冬天里，可能什么事情都没发生，而那完全没有问题。


在活动比较少的月份，你也许只是在笔记本里写写日记：


少一点输出，多一点让输入进来、在脑中翻搅。


两者都需要。


植物提醒我们，生命讲究的是平衡。


待在户外整理自己的花园，是一件很舒服的事。


同样地，安静地陪着自己的想法，把它们一个个放到不同页面上，也很好。


_Fred Rogers_


### 网站是一滩水洼


网站也可以是一滩水洼。


水洼是一小片暂时聚集起来的雨水。


它们通常出现在暴雨之后。


而制作网站，也可以像一场暴风雨一样，在某个瞬间猛然爆发。


有时候，分几次这样突然进入状态、猛烈地做网站，其实很好，因为那种创作的“状态”实在太难捉摸。


甚至有人把下雨天叫作“电脑天气”。


网站也和水洼一样，不存在所谓“完成”的状态，因为它们本来就是短暂的。


有时，水洼可以非常大，表面像镜子一样反射周围。


尽管它们只是暂时存在，我甚至见过一些生物在水洼里活得很好。


另一方面，有些小水洼可能一天就消失了。


并不是所有东西都必须长久存在。


即使是一滩极其美丽、倒映着令人惊叹景象的水洼，也不需要永远留下来。


只要世界明天没有毁灭，总还会有下一场雨。


而只要地上有一个凹洞，水洼就会再次出现。


水洼会随着时间慢慢蒸发。


也许很难做到，但我真的很想有一天看见一个网站，也能慢慢蒸发。


### 网站是一颗被扔出去、正在沉入深海的石头


有时候，你并不想做一个之后还得一直维护的网站。


你还有其他事情要做。


那为什么不把自己的网站想成一颗美丽而形状独特的石头？


你花了好几个小时才找到它，然后把它扔进水里，任由它一路下沉，直到海底。


你永远不会知道它什么时候碰到海床。


而你也不在乎。


幸好，石头到处都是。


如果你喜欢，这件事可以一次又一次地做。


你想往海里扔多少个网站都可以。


每当一个想法出现，就找一颗石头，把它扔出去。


## Web 是我们共同塑造出来的


一个网站可以是上面提到的任何一种隐喻。


但我认为，目前最普遍的一个隐喻——把互联网称作“云端”——其实有问题。


互联网并不是某种笼罩一切、神秘而不可触及的单一存在。


早期描述互联网的专利图里，也曾出现过类似的形象：一团东西、一颗脑，或者一次爆炸。


这些隐喻掩盖了一个事实：


互联网其实是由一个个独立节点组成的。


一台电脑，正在和另一台电脑说话。


万维网（World Wide Web）最近刚满 29 岁。


在 Web 生日那一天，它的创造者 Tim Berners-Lee 发表了一封公开信，谈到今天的 Web 正面临哪些威胁。


他指出，虽然它叫作“World Wide Web”，但全球只有大约一半人口已经连上网，因此我们应该努力缩小这道数字鸿沟。


但与此同时，Berners-Lee 也希望确保：


我们所有人正在连接上的这个东西，真的能够为我们每一个人服务。


他写道：


> 我想挑战我们所有人，对 Web 抱持更大的企图。我希望 Web 能映照我们的希望、实现我们的梦想，而不是放大我们的恐惧，加深彼此之间的分裂。


George Lakoff 与 Mark Johnson 在 1980 年出版的《我们赖以生存的隐喻》（_Metaphors We Live By_）中写道：


> “隐喻把理性与想象连接在一起。”


	“隐喻并不只是一些可以被我们超越的东西。事实上，我们若想超越一个隐喻，也只能借助另一个隐喻。通过隐喻理解经验的能力，就像视觉、触觉或听觉一样，是一种感官；而对世界许多部分的感知与体验，也只有通过隐喻才得以发生。隐喻和触觉一样，是我们日常运作不可分割的一部分，也同样珍贵。”


所以，与其把互联网想成一朵“云”，不如换一个能让 Web 中那些独立、彼此合作的节点更容易被看见的隐喻。


这样一来，我们才会记得：


在打造一个更好的 Web 这件事上，我们每个人都负有一份责任。


Web 可以是一群飞鸟，也可以是一片标点符号的海洋。


其中每一个个体，都可能正在照料自己的网络花园，也可能早已把它忘了；


可能住在一滩水洼里，而不远处，正流着一条知识之河。


如果网站具有无穷的可能，而我们的身份、想法与梦想，也会通过网站被创造、拓展，那么，让网站和我们一起成长，就非常重要。


尤其当各种力量仍持续威胁着 Web，以及更广大的互联网时，这件事就更加迫切。


在这个信息过载、Web 也日益商业化的年代，各种类型的艺术家都能伸出援手。


艺术家能以更开阔的方式去想象：


**网站究竟可以是什么？**


每一位艺术家，都应该在 Web 上建立一个属于自己的空间。


因为——


**一个网站，是以个人之力完成的一项集体雄心。**
