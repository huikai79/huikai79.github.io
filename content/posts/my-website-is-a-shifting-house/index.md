## 什麼是網站？


過去幾年，我一直在教授互動設計與網際網路相關的課程。


我是在大學的藝術相關科系裡教課，所以我們會討論網際網路如何影響藝術，也會反過來看藝術如何影響網際網路，以及科技進步為什麼經常與藝術發展同步發生。


課堂上，我們會製作網站。為了做到這件事，我們會學習構成網頁最基本的標記與程式語言——HTML、CSS，以及一些 JavaScript。


然而，有時一個學期結束後，我還是會收到學生困惑的 Email，問我：


「所以，我到底要怎麼**真正做出一個網站**？」


這也讓我開始問自己：


「話說回來，網站到底是什麼？」


我們很容易忘記這件事。今天，製作網站的方法多到數不清，選擇多得令人無所適從。但從最根本來看，網站其實一直都沒有改變：


網站，就是放在某處伺服器上的一個檔案，或一組檔案。


伺服器是一台持續連上網際網路的電腦。當有人輸入你的網址時，伺服器就會把你的網站送出去。通常你需要付費使用伺服器，也需要付費購買網域名稱。


網域名稱是一串人比較容易理解的文字，用來指向一個 IP 位址；而 IP 則是一串數字，代表你的伺服器位於哪裡。


連結——預設通常顯示成藍色並帶有底線——是網路的氧氣。它們就是 HTML 裡「HT」，也就是 hypertext（超文字）的核心。


不是每一個網站都有連結，但所有連結都會把你帶往其他網頁：可能仍在同一個網站裡，也可能前往別的地方。


可是，這些我的學生早就知道了！


所以，當他們問我到底要怎麼**真正做一個網站**時，他們其實是在問：


要怎麼做一個存在於**今天這個世界裡**的網站？


我們應該承認，今天的網路，已經和許多人從小熟悉的那個網路很不一樣。


因此，學生明明已經「學會」了做網站，卻還是會問該怎麼做，真正困住他們的，其實是 2018 年製作與維護網站時伴隨而來的技術阻力，以及社會壓力。


那些人人都在使用的社群網站——Facebook、Instagram、Snapchat、Pinterest 等——乍看之下可能很友善、很方便，但它們終究是私人企業，而且廣告利益的優先順序高於使用者的需求。


使用者快不快樂，並不是它們最主要的考量。


所以，當你使用社群媒體，甚至只是想到社群媒體時感到焦慮，其實再正常不過。


在這個由大型平台主導、充斥數位噪音的年代，沒有人會替你照看你自己——除了你自己。


因此，當有人告訴我，他希望自己的網站能夠「把事情說清楚」，清楚表明自己是誰、在做什麼，我完全可以理解。


然而，「清楚」只是網站眾多可能目的中的其中一種。


人還有很多不同的心理狀態，都可以透過網站傳達。


一個令人驚喜的網站、一個讓人難忘的網站、一個宏大的網站、一個令人平靜的網站、一個震撼的網站、一個難以預測的網站、一個無聊到極致的網站、一個古怪的網站、一個讓人大開眼界的網站、一個非常安靜細膩的網站，或者單純一個很棒的網站——都可以成立。


你甚至不需要只做一個網站。


搞不好，你就是想用好幾個網站讓人困惑，或給人驚喜。


我最喜歡網站的一點，是它同時具有兩種身分：它既是主體，也是客體。


換句話說，網站的創作者同時是作者，也是建築師。


網站可以成為什麼，幾乎沒有盡頭。


網站是一個什麼樣的房間？


或者，網站其實更像一棟房子？


一艘船？


一朵雲？


一座花園？


一灘水窪？


無論它是什麼，都可能形成一種自我回饋的循環：


當你把心力投入網站，網站也會反過來塑造你的身分。


## 為什麼要有自己的網站？


我們比任何時候都更需要由一個個人，而不是由企業，來引導網路的未來。


Web 之所以叫做「網」，正是因為它的生命力依賴這樣的結構——一個個彼此連結的獨立節點，共同為龐大的網絡注入生命。


這張網真正應該服務的是人，而不是由少數幾家大型企業——例如 Facebook／Instagram、Twitter 和 Google——提供動力並掌控方向。


只要擁有自己的網站，每一個人其實都可以把 Web 拉回它最初的架構。


我尤其認為，藝術家可以在這件事上扮演關鍵角色——讓世界看見，Web 還能走向哪些地方。


藝術家很擅長創造世界。


他們先替自己創造一個世界，然後在分享作品時，也替其他人打開那個世界。


而所謂「建構世界」，當然意味著你得創造一切。


你不只是製作這個世界裡面的東西，也要創造包圍它們的整個世界——它的語言、風格、規則與建築。


這正是網站如此重要的原因。


網站讓作者不只可以創造作品，也就是那些「物件」，還能創造承載作品的世界——房間、房間的排列方式，以及整體的建築。


理想狀態下，這兩者會彼此影響，形成一個良性、不斷自我完善的循環。


對藝術家的創作實踐而言，這可能是一件非常滋養人的事。


每當有創作者說：


「我不需要網站。」


我會反問：


為什麼不做一個能在策略上與其他活動並行的個人網站？


網站怎樣才能補足你原本就在做的事，而不是和它競爭，或只是把同樣的東西再做一次？


你怎麼讓製作網站這件事，對自己而言變得有趣、引人思考，或者帶來任何你想要的感受？


製作與培養一個網站的過程，又能怎樣反過來影響你的創作方式？


網站可以是任何東西。


它不必——而且很可能也不應該——成為你所有作品的完整檔案庫。


因為那樣的東西，在你發布的那一刻就已經死了。


網站，以及任何互動性的事物，本質上都處於未完成狀態。


它不完美。有時甚至還會有幾個 bug。


但這正是它美麗的地方。


網站是活著的，也是具有時間性的空間。


話說回來，網站死去之後，究竟會發生什麼事？


## 網站可以是什麼？


### 網站是一個房間


在資訊過載的時代，房間令人安心，因為它有邊界，而且通常有某個特定用途。


_Louis Rosetto_


同時，房間也可以非常有彈性。


你可以依照不同場合重新排列裡面的東西，甚至暫時加上一面隔間。


你也可以把不同元素放在空間裡彼此並置，或者利用連結打開通往隔壁房間的入口。


在 The Creative Independent（TCI）成立初期，我們有時會把 TCI 的網站想像成一棟蓋在河邊的房子。


我們把那些訪談想成不斷流動的河水，因為它們是這棟房子的養分，也是生命來源。


每天，我們都從河裡取水、喝水。


但有時，根據水裡養分組成的不同，河水也會改變我們的房子。


我們可能一覺醒來，發現原本掛著畫框的地方，突然多出了一扇門。


**知識成了建築師。**


當然，任何隱喻都不可能完美。


不論是好是壞，要拆掉一棟建築，遠比刪掉一個網站困難多了。


_Orit Gat_


### 網站是一個架子


如果把視線拉近，看看這棟房子裡的這個房間，我們會看到一個架子。


或許，比起思考一整個房間，先想像一個架子要容易一些。


架子上要放什麼？


書？


生活中收集來的物件？


當然，都可以。


幸好架子上沒有什麼太重的東西，不然架子可能會垮掉。


放幾樣小東西就夠了——它們可以承載知識，也可以完全不承載什麼。


而且，東西越輕，就越容易更換。


有一本書或一件小飾物已經「太去年」了嗎？


那就把它拿下架吧。


想一想，你可以在這個小小的架子上，創造出哪些出人意料的並置。


### 網站是一株植物


植物是催不得的。


它們會按照自己的方式生長。


你的網站也可以如此——只要選對土壤，替它澆水，但不要澆太多，再給它足夠的陽光。


某一天，種下一顆想法的種子，然後讓它慢慢長大。


也許過了幾年，它才會開花。


運氣好的話，再過一年，它可能結出果實。


果實可以是朋友，可以是欣賞，也可以是金錢——成功有很多種形式。


但別太興奮，也別急著替自己設定目標。


這裡談的不是那回事。


我說過了：


**植物是催不得的。**


_Paul Ford_


### 網站是一座花園


Fred Rogers 曾說，你可以在自己的心靈花園裡培養想法。


有時，等這些想法長成小小的幼苗，已經可以自己站穩之後，把它們移到外面的花園，種在其他幼苗旁邊，也會很有幫助。


花園每個季節都有自己的節奏。


冬天裡，可能什麼事情都沒發生，而那完全沒有問題。


在活動比較少的月份，你也許只是在筆記本裡寫寫日記：


少一點輸出，多一點讓輸入進來、在腦中翻攪。


兩者都需要。


植物提醒我們，生命講究的是平衡。


待在戶外整理自己的花園，是一件很舒服的事。


同樣地，安靜地陪著自己的想法，把它們一個個放到不同頁面上，也很好。


_Fred Rogers_


### 網站是一灘水窪


網站也可以是一灘水窪。


水窪是一小片暫時聚集起來的雨水。


它們通常出現在暴雨之後。


而製作網站，也可以像一場暴風雨一樣，在某個瞬間猛然爆發。


有時候，分幾次這樣突然進入狀態、猛烈地做網站，其實很好，因為那種創作的「狀態」實在太難捉摸。


甚至有人把下雨天叫做「電腦天氣」。


網站也和水窪一樣，不存在所謂「完成」的狀態，因為它們本來就是短暫的。


有時，水窪可以非常大，表面像鏡子一樣反射周遭。


儘管它們只是暫時存在，我甚至見過一些生物在水窪裡活得很好。


另一方面，有些小水窪可能一天就消失了。


並不是所有東西都必須長久存在。


即使是一灘極其美麗、倒映著令人驚嘆景象的水窪，也不需要永遠留下來。


只要世界明天沒有毀滅，總還會有下一場雨。


而只要地上有一個凹洞，水窪就會再次出現。


水窪會隨著時間慢慢蒸發。


也許很難做到，但我真的很想有一天看見一個網站，也能慢慢蒸發。


### 網站是一顆被扔出去、正在沉入深海的石頭


有時候，你並不想做一個之後還得一直維護的網站。


你還有其他事情要做。


那為什麼不把自己的網站想成一顆美麗而形狀獨特的石頭？


你花了好幾個小時才找到它，然後把它扔進水裡，任由它一路下沉，直到海底。


你永遠不會知道它什麼時候碰到海床。


而你也不在乎。


幸好，石頭到處都是。


如果你喜歡，這件事可以一次又一次地做。


你想往海裡扔多少個網站都可以。


每當一個想法出現，就找一顆石頭，把它扔出去。


## Web 是我們共同塑造出來的


一個網站可以是上面提到的任何一種隱喻。


但我認為，目前最普遍的一個隱喻——把網際網路稱作「雲端」——其實有問題。


網際網路並不是某種籠罩一切、神祕而不可觸及的單一存在。


早期描述網際網路的專利圖裡，也曾出現過類似的形象：一團東西、一顆腦，或者一次爆炸。


這些隱喻掩蓋了一個事實：


網際網路其實是由一個個獨立節點組成的。


一台電腦，正在和另一台電腦說話。


全球資訊網（World Wide Web）最近剛滿 29 歲。


在 Web 生日那一天，它的創造者 Tim Berners-Lee 發表了一封公開信，談到今天的 Web 正面臨哪些威脅。


他指出，雖然它叫做「World Wide Web」，但全球只有大約一半人口已經連上網，因此我們應該努力縮小這道數位落差。


但與此同時，Berners-Lee 也希望確保：


我們所有人正在連上的這個東西，真的能夠為我們每一個人服務。


他寫道：


> 我想挑戰我們所有人，對 Web 抱持更大的企圖。我希望 Web 能映照我們的希望、實現我們的夢想，而不是放大我們的恐懼，加深彼此之間的分裂。


George Lakoff 與 Mark Johnson 在 1980 年出版的《我們賴以生存的譬喻》（_Metaphors We Live By_）中寫道：


> 「隱喻把理性與想像連結在一起。」


	「隱喻並不只是一些可以被我們超越的東西。事實上，我們若想超越一個隱喻，也只能藉助另一個隱喻。透過隱喻理解經驗的能力，就像視覺、觸覺或聽覺一樣，是一種感官；而對世界許多部分的感知與體驗，也只有透過隱喻才得以發生。隱喻和觸覺一樣，是我們日常運作不可分割的一部分，也同樣珍貴。」


所以，與其把網際網路想成一朵「雲」，不如換一個能讓 Web 中那些獨立、彼此合作的節點更容易被看見的隱喻。


這樣一來，我們才會記得：


在打造一個更好的 Web 這件事上，我們每個人都負有一份責任。


Web 可以是一群飛鳥，也可以是一片標點符號的海洋。


其中每一個個體，都可能正在照料自己的網路花園，也可能早已把它忘了；


可能住在一灘水窪裡，而不遠處，正流著一條知識之河。


如果網站具有無窮的可能，而我們的身分、想法與夢想，也會透過網站被創造、拓展，那麼，讓網站和我們一起成長，就非常重要。


尤其當各種力量仍持續威脅著 Web，以及更廣大的網際網路時，這件事就更加迫切。


在這個資訊過載、Web 也日益商業化的年代，各種類型的藝術家都能伸出援手。


藝術家能以更開闊的方式去想像：


**網站究竟可以是什麼？**


每一位藝術家，都應該在 Web 上建立一個屬於自己的空間。


因為——


**一個網站，是以個人之力完成的一項集體雄心。**
